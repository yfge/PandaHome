# Establish strict development paradigm

## Summary
- Created repo-wide standards inspired by talkReplay, orion, ai-shifu, and talkreplay.com.
- Added canonical `agents.md`, enforced `agent_chats` workflow, and wired pre-commit automation.

## Changes
- New `agents.md` handbook defining mission, tooling, hooks, and API references.
- Introduced `agent_chats/` directory with README, log template, and this entry.
- Added `.pre-commit-config.yaml` plus helper scripts (`scripts/ensure_agent_chat.sh`, `scripts/run_web_lint.sh`).
- Simplified `CLAUDE.md` to point at `agents.md` while highlighting critical reminders.
- Updated `README.md` / `README.zh.md` to document tooling install, agent_chats workflow, and corrected stack details.
- Scoped the Ruff hook to lint/fix Python without auto-formatting entire files.
- Replaced a bare `except` in `api/src/app/services/upnp.py` with `except OSError` and let Ruff clean trailing whitespace/unused imports for hook compliance.

## Outcome
- Repository now blocks commits without matching `agent_chats` entries when code changes.
- Linting runs automatically for FastAPI (Ruff) and Next.js via pre-commit.
- Agents share a single source of truth for workflows and environment expectations.

## Verification
- `pre-commit run --files api/src/app/services/upnp.py`
